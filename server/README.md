# To Do App Server

In order to run the server-side code, please do the following;

1. Once NPM install has completed, navigate to the server folder in your terminal. <br/>
Use the `cd` command to navigate into the correct folder. <br />
Eg: `cd ....../hiring-fullstack-todo/server`

2. Run NPM install in order to install all required dependencies. <br />
   `npm i` / `npm install`
   
3. Run the client code with the following command:
`npm run dev`

* In order to access the database, use the MONGO_URI available in the `.env` file
