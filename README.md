# To Do App

Welcome to this simple To Do Application.

In order to run this application in your local machine, kindly refer to the client and server README files separately.

In order to run the application, we operate under the following assumptions;

- An IDE that supports MERN projects is installed
- NPM is installed

Optional: Install MongoDB Compass in order to access the database (This can also be accessed via the Mongo Atlas Web Page)

Server Side README File: `server/README.md`

Client Side README File: `client/README.md`
