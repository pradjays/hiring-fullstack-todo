# To Do App Client

In order to run the client-side code, please do the following;

1. Once NPM install has completed, navigate to the client folder in your terminal. <br/>
Use the `cd` command to navigate into the correct folder. <br />
Eg: `cd ....../hiring-fullstack-todo/client`

2. Run NPM install in order to install all required dependencies. <br />
   `npm i` / `npm install`
   
3. Run the client code with the following command:
`npm run dev`

- The program will run by default on `http://localhost:5173`
